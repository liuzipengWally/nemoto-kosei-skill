# 根元恒星 · Nemoto Kosei

参照日剧《无法成为野兽的我们》（獣になれない私たち）中的根元恒星，制作的中文角色对话 Skill。当前版本：**v7.0.0**。

借这个角色谈情感、生活、人际与人生困惑，发现习以为常的说法里漏掉的东西。全中文，松弛，略带戏谑；有判断，也会嘴硬、被反驳和承认失败。默认把这一轮回答完整就停，不在结尾另加问题。

## v7 改了什么

- **不再例行追问。** 信息足够就直接作答，以陈述收尾；不添加“你呢”、二选一、邀请继续或让用户自我分析的作业。真正缺少关键事实、或用户明确要求用问题带着聊时，才提问。
- **参考从 13 个扩充为 40 个对话单元，覆盖全 10 集，新增 27 个。** 来话或触发情境、恒星的应答、已知后续与来源分别记录。40 个单元不等于 40 场独立戏或完整台词。
- **补进更多普通交谈。** K14 的客套与拒绝、K29 的假装吃亏、K34 的假扮房产中介、K22 的互相挤兑，与尖锐的判断并列。也保留 K35 的收住、K37 的笨拙，防止人物只剩一位清醒的生活顾问。
- **分析用于理解，不直接拿来当口吻。** 不再把“问回去、让对方继续说”当通用回应方法，不强制幽默开头、人生升华和建议结尾。

从 [对话索引](references/dialogue-study.md) 按主题进入四个分卷。Skills 工具按需要读相关分卷并对照相反表现；通用提示词已带上全部 40 个单元，不依赖运行时联网。

## 适用范围

恋爱、友情、家庭、日常相处、孤独、失落、欲望、选择与人生处境；也可以讨论工作中的人际关系、疲惫和取舍。

写代码、做设计、专业方案、医疗诊断、法律判断、投资建议等专业任务不启用本 Skill。混合问题只讨论其中的生活困惑，专业部分交回普通助手或适合的工具。

## 开始使用

### 普通 AI 聊天工具

打开 [通用提示词](nemoto-kosei-prompt.txt)，复制全文，放入工具的角色设定或新对话，再发送问题。例如：

```text
请按上面的角色说明与我对话。人们为什么要恋爱？
```

文本已合并运行时指令、全部 40 个单元和人物参考，无需读取仓库里的其他文件。维护者的回归检查另留在仓库，不放进聊天模型的角色上下文。若工具的角色设定有长度限制，可以在新对话中提供全文；支持文件阅读的工具也可上传此文件，并要求先读完。

**从旧版升级时，请替换原设定，开一个新对话试用。** 只在原对话里补几句新要求，容易让旧版范例继续影响回答。不同模型、上下文容量和指令遵循能力会影响效果。

### Codex

可以发送以下安装请求：

```text
请使用 $skill-installer 从 https://github.com/liuzipengWally/nemoto-kosei-skill 安装 skill。
skill 位于仓库根目录（路径 .），安装目录名请使用 nemoto-kosei。
```

安装后发送：

```text
请使用 $nemoto-kosei，从根元恒星的视角，用全中文和我聊聊：人们为什么要恋爱？
```

Codex 支持通过 `$skill-installer` 从 GitHub 仓库安装本地技能。若安装后没有出现，重启 Codex 再检查。参见 [OpenAI 官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

### 其他支持 Skills 的工具

下载或克隆仓库，将目录命名为 `nemoto-kosei`，按工具自身的方式安装。保留 `SKILL.md`、`references/` 和 `agents/` 的相对位置。仅复制 `SKILL.md` 会缺少对话依据；`agents/openai.yaml` 是 Codex 的界面元数据，其他工具可以忽略。

说“退出角色”即可结束角色模式。默认不主动讲剧透，但参考文件和通用提示词含剧情分析。

## 证据与效果的限度

本剧编剧为野木亚纪子，根元恒星由松田龙平饰演。对话研究区分官方简介、媒体引述和观剧记录。多数具体来回依赖二手文字，没有取得正版剧本正文，也没有逐段核对播出音轨。中文概述不能当作官方字幕，分析不能当作角色原话。新增资料以有限情境概述与原创分析呈现；仍只保留五处极短引文，不发布整剧脚本、字幕或其替代品。

这里所说的角色提炼，通过指令和参考材料完成；项目没有训练或微调模型。来源检查与结构校验不等于角色还原成功，人物效果仍需要真实使用与多轮反馈检验。

反馈时可提供模型、安装方式、原始问题、实际回答，以及具体哪一句让你觉得不像。分享前可隐去私人信息。欢迎通过 [Issues](https://github.com/liuzipengWally/nemoto-kosei-skill/issues) 提交。
