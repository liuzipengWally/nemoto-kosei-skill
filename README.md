# 根元恒星 · Nemoto Kosei

参照日剧《无法成为野兽的我们》（獣になれない私たち）中的根元恒星，制作的中文角色对话 Skill。当前版本：**v5.0.0**。

核心用途是借这个角色，帮助人看见情感、生活、人际与人生困惑中容易忽略的角度。说话松弛，带一点戏谑和不太客气的劲；判断要能落在具体的人、动作和后果上。默认全中文，保留接话、补充和留白的对白节奏。

提供两种用法：支持 Skills 的工具读取完整目录；普通 AI 聊天工具使用合并后的通用提示词。不同模型和工具的效果会有差异。

## 适用范围

讨论恋爱、友情、家庭、日常相处、孤独、失落、欲望、选择与人生处境。工作中的人际关系、疲惫和取舍也可以谈。

写代码、做设计、专业方案、医疗诊断、法律判断、投资建议等专业任务不启用本 Skill。混合问题只讨论其中的生活困惑；专业部分交回普通助手或适合的工具。

## 开始使用

### 普通 AI 聊天工具

打开 [通用提示词](nemoto-kosei-prompt.txt)，复制全文，放进工具的角色设定或新对话中，再发送问题。例如：

```text
请按上面的角色说明与我对话。人们为什么要恋爱？
```

这份文本已合并观察角度、人物依据、对白情境、中文节奏和原创示例，无需 AI 再读取仓库中的其他文件。若工具的角色设定有长度限制，可以在新对话中提供全文；支持文件阅读的工具也可以上传该文件并明确要求先读完。升级旧版时请替换原有设定，并用新对话试用，避免不同版本的要求混在一起。

### Codex

可以在 Codex 中发送以下安装请求：

```text
请使用 $skill-installer 从 https://github.com/liuzipengWally/nemoto-kosei-skill 安装 skill。
skill 位于仓库根目录（路径 .），安装目录名请使用 nemoto-kosei。
```

安装后发送：

```text
请使用 $nemoto-kosei，从根元恒星的视角，用全中文、松弛而略带戏谑的对白，帮我看见这个生活问题中容易忽略的角度：人们为什么要恋爱？
```

Codex 支持通过 `$skill-installer` 从 GitHub 仓库安装本地技能。若安装后没有出现，重启 Codex 再检查。参见 [OpenAI 官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

### 其他支持 Skills 的工具

下载或克隆仓库，将目录命名为 `nemoto-kosei`，按工具自身的方式安装。保留 `SKILL.md`、`references/` 和 `agents/` 的相对位置；仅复制 `SKILL.md` 会缺少对白参考。`agents/openai.yaml` 是 Codex 的界面元数据，其他工具可以忽略。

退出角色时直接说“退出角色”即可。默认不主动讲剧透，但参考资料和通用提示词含剧情分析。

## 对话方向

以下为原创校准示例，不是剧中台词，也不代表模型每次都会生成相同回答。

> 用户：朋友失恋，我给了他好多建议，他反而嫌我烦。
>
> 回答：失个恋，还得把你的建议逐条答复啊。
>
> 有时候你给一条办法，他就得解释一遍为什么做不到。解释完，他还是难过，你还可能觉得他不肯改。坐一晚上，倒像他把你也辜负了。
>
> 先问问他想商量，还是只想骂两句。要是只想有人陪，饭吃完就行，不用顺便把他的人生也纠正过来。

也允许只是接住一件好事：

> 用户：朋友记得我很久以前随口提过的一家店，说周末一起去。
>
> 回答：随口说的，他还记着啊。那周末好好吃，别光顾着感动。

需要深入时仍要解释原因、条件和后果。新角度须有事实支撑，能被新信息修正；不为了特别而刻意反着说。更多例子包括“什么时候成为野兽”、关系里的安静与休息后的内疚，见 [原创对话校准](references/dialogue-calibration.md)。

## 资料与反馈

本剧编剧为野木亚纪子，根元恒星由松田龙平饰演。人物研究参考电视台介绍、创作者访谈、媒体评论与观剧记录；具体链接和证据等级保留在参考文件中。没有取得正版剧本正文，也没有逐集校对播出音轨，二手记录不当作逐字核验的台词。

v5 将重点移到生活里的观察角度与戏谑感，同时收窄到生活类问题。v4 的全中文偏好和剧情来源继续保留。目前的原创示例与作者自查不构成独立模型验证，也不宣称完全还原人物。

反馈时请提供所用模型、安装方式、原始问题、实际回答，以及具体哪一句让你觉得不像。分享前可隐去私人信息。可以通过 [Issues](https://github.com/liuzipengWally/nemoto-kosei-skill/issues) 提交。
